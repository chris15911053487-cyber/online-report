在线报表系统 · 六种界面主题

同一批真实场景（菜单、生产报工、Agent 与 BI 看板、设置与管理后台）按三种风格分别绘制，数据为示例。手机模式下六种主题并排对比；正式版默认 D，用户可在设置里切换；切到 PC 模式可看侧边栏导航和带地址的页面（引入 URL 路由后的样子）。

风格

A 科技风

特点
延续现在登录页的青-靛-紫；Agent 入口、头像、重点 KPI 用渐变；圆角大、阴影柔和
适合
想突出"AI 系统"的新鲜感，对外演示效果好
注意
表格多、要长时间看数据的页面，渐变和大圆角会显得花哨

B 稳重企业风

特点
单一蓝色，圆角 8，几乎无阴影，字号 13，信息密度最高；观感接近钉钉、飞书后台
适合
报表、报工这类天天用的业务页面；在钉钉里打开不突兀
注意
个性较弱，AI 功能不会显得特别"亮"

C 深色工业风

特点
深色顶栏、侧栏和底栏，浅色内容区；数字用等宽字体，KPI 顶部色条，看板感最强
适合
管理层看板、车间大屏、监控类页面
注意
手机上深色顶栏在钉钉白色界面里比较跳；表单页优势不明显

D 暖色人文风

特点
象牙白底、陶土橙强调色，标题和 KPI 数字用衬线体；无阴影、留白多，气质接近 Anthropic / Claude
适合
以 AI 对话、分析解读为主的页面，读起来像文档，长时间看不累
注意
衬线中文字体要额外加载（约几百 KB，按需分片）；密集表格需单独调紧凑

E 极简黑白风

特点
黑白灰为主，按钮和重点数据用纯黑，颜色只留给状态（红/绿/橙）；细边框、小圆角
适合
偏现代互联网产品的观感，状态色在黑白底上非常醒目
注意
对车间一线用户偏"冷"，按钮区分度靠形状和文字，不靠颜色

F 全深色

特点
内容区、卡片、图表全部深色，低饱和蓝紫强调，状态色调亮以保证对比度
适合
夜班、车间大屏、长时间盯看板；可跟随系统深色模式自动切换
注意
报表里的图片列、导出的文件仍是浅色，需单独处理边框和底色

演示只用于选风格，不包含真实数据，也不代表最终细节。选定后再统一做组件库与全部页面改造。
