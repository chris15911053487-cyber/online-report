# 生产报工（合并报工）

## 入口

1. 点击底部 **「菜单」**。
2. 在菜单网格中选择 **生产报工类菜单**（常见名称如「生产报工登记」；`route_key` 多为 `pro-sign`，以贵司配置为准）。

进入后为报工列表：可设置筛选条件、勾选多行，底部有吸底主按钮。

## Status 筛选与底部按钮（固定规则）

列表筛选中的 **Status** 决定底部按钮文案及下一页操作类型（按选项 **code** 固定映射）：

| Status code | 列表吸底按钮 | 合并页操作 |
|-------------|-------------|------------|
| **0** | **接单** | 选操作员、确认数量后保存接单 |
| **1** | **完工** | 主按钮「完工」；另有 **「暂停报工」**（琥珀色） |
| **8** | **恢复报工** | 仅「恢复报工」主按钮（暂停后继续） |
| 其它 / 未选 | **合并报工** | 常规合并保存 |

**说明**：Status 下拉通常不含「全部」；打开页面后默认会选中第一项（多为待接单 code=0）。

## 标准业务流程

### 1. 接单（Status = 0，待接单）

1. 将 Status 选为 **待接单**（code **0**）。
2. 点击 **查询**，勾选需要接单的行（需含有效 DocEntry、StepCode）。
3. 点击底部 **「接单」**，系统预检通过后进入合并页。
4. 选择操作员（可点「仅本人」或搜索勾选；不选则默认当前登录账号）。
5. 核对每行数量，点 **「接单」** → 确认 → 保存。成功后返回列表。

### 2. 完工（Status = 1，待完工）

1. 将 Status 选为 **待完工**（code **1**）。
2. 查询并勾选要完工的行。
3. 点击底部 **「完工」**，进入合并页。
4. 选操作员、核对数量后：
   - 点主按钮 **「完工」** 完成汇报；或
   - 点 **「暂停报工」**，可填备注，确认后以「暂停报工」类型单独保存（与完工为不同 SignType）。

### 3. 暂停报工之后如何继续（重要）

暂停后工单处于暂停状态，需用 **恢复报工** 流程继续：

1. 返回生产报工列表。
2. 将 Status 选为 **恢复报工**（code **8**）。
3. 查询并勾选对应行。
4. 点击底部 **「恢复报工」**，在合并页确认后保存。

**不要**在仍为「待完工」(code=1) 时重复点「暂停报工」处理已暂停的单据；应使用 code=8 的恢复流程。

### 4. 其它 Status（合并报工）

未匹配 0/1/8 时，底部显示 **「合并报工」**，按常规合并保存，无「暂停报工」副按钮。

## 列表其它操作提示

- 必须 **先勾选行** 再点底部按钮；未勾选会提示。
- 从合并页 **返回** 后，筛选条件会保留，并 **自动重新查询** 列表。
- 手机填写筛选条件弹出键盘时，底部吸底按钮会 **暂时隐藏**，收起键盘后恢复。
- 勾选多行时，按钮上会显示数量，如「接单 (3)」。

## 与批次报工的区别

本系统另有 **批次报工**（`X_report_batch` + 计时暂停/继续），入口为其它菜单，流程与上述 **合并报工**（`X_ONLINE_SIGN`）不同。若菜单名含「批次」，请按该菜单界面指引操作。
