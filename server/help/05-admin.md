# 管理员功能（简要）

## 菜单设置

仅 **admin** 角色用户可在菜单中看到「菜单设置」：

- 新增/编辑报表菜单：SQL 模板、筛选 schema、列映射、AI Prompt 等。
- **手机卡片（可选）**：给报表配一段卡片布局 JSON，手机上就用卡片代替表格（电脑上仍是表格）。每个位置写一组候选列名，按顺序取查询结果里有的第一列，所以不同筛选返回不同列也没关系；没用到的列自动排在卡片下半部分，`hidden` 里的不显示。字段说明见输入框里的示例。
- 生产报工菜单通常 `route_key` 为 `pro-sign`，`menu_kind` 为报表类。

## 给操作员开通报工

1. 确认菜单 **已启用**。
2. `roles_json` 包含 `operator`（或对应角色）。
3. Status 下拉选项的 **code** 需与系统约定一致：**0 接单、1 完工、2 已完工、8 恢复报工**。

若 code 与约定不一致，底部按钮可能显示「合并报工」而非「接单/完工/恢复报工」。
