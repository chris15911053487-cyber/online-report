# 消息：通知与待办

「消息」集中显示系统主动发给你的内容和要你处理的事。电脑上在左侧菜单，手机上在底部「消息」Tab；入口上的红色数字 = 未读通知 + 你的待处理待办。

页面分两个页签：

- **通知**：警报、定时报告、看板每日要点、每日待办汇总等推送给你的内容，按时间倒序，一条一条留存。
- **待办**：系统按数据找出来、归到你名下要处理的事（如「超期未完工的工单」），处理完才算结束。

## 通知

管理员配置的**警报**（如「物料低于安全库存」）和**定时报告**（如每日生产日报、看板每日要点）触发后，会同时做两件事：

1. 在系统「消息 → 通知」里给你留一条；
2. 如果你的账号绑定了钉钉，再发一条钉钉消息。

所以没绑定钉钉也不会漏看，钉钉里的消息被刷走了也能回到系统里找。

**看通知**：列表显示标题、摘要、来源（警报 / 报告 / 待办）和时间，未读的标题加粗、前面有红点。点开看全文，打开即算已读。警报配置了「查看详情」按钮的，全文下方有对应按钮，可以跳到相关报表或页面。

**筛选与已读**：顶部「全部 / 未读」切换；「全部标为已读」一次清掉未读。往下翻到底点「加载更多」看更早的通知。

## 钉钉里的消息

钉钉消息的标题、正文与系统里的通知一致。消息底部的按钮：

- 警报配置了按钮（如「查看详情」）时，直接打开配置的地址；
- 待办汇总、新待办、转交通知显示「查看待办」，点开直接到系统「消息 → 待办」；
- 其他情况显示「在系统中查看」，点开就是系统里这条通知的全文（同时标为已读）。

收不到钉钉消息时，先确认能在系统「消息 → 通知」里看到这条；看得到而钉钉没收到，一般是账号还没绑定钉钉，请联系管理员。

## 待办：每天早上推给你

待办由管理员在「管理后台 → 预警与待办」里配置规则，系统按数据每行生成一条，归到数据里的负责人名下（比如工单上的计划员）。同一张单据只会有一条待办。

**每天早上 7:30** 左右，有待办的人会收到一条「今日待办 N 条（超期 M）」，列出最紧急的 5 条，点「查看待办」进系统看全部。没有待办就不推。**下午 3 点**再复查一次，今天到期或已经超期、还没处理的会再提醒一次。

列表默认按到期日排：红色「超期 N 天」、黄色「今天到期」在最前面。顶部可切换：

- **待处理**：要你处理的；
- **已延后**：你延后过、还没到日子的；
- **最近完成**：最近 30 天处理掉的。

## 待办：怎么处理

点一条展开，能看到说明、数据明细和处理记录，下面是操作按钮：

- **已处理**：处理完点这个。注意**以数据为准**：第二天系统重新查数据时，这张单据还在（比如工单还是没完工），待办会自动重新打开；查不到了就自动关闭。所以真正的「完成」是把单据处理掉。
- **延后**：暂时处理不了（如等物料），选「明天 / 3 天后 / 下周一」或指定日期，到那天恢复为待处理。可以写原因。
- **转交**：不归你管的，搜索同事转给他，对方会收到通知。转交后负责人就固定了，不会再随数据变回来。
- **备注**：记录处理进展，主管能看到。
- **打开单据**：管理员配置了链接的，直接跳到对应报表或单据。

处理了的单据数据里查不到了，待办会自动关闭，不需要再点「已处理」。

## 待办：主管看团队

规则的推送对象是**主管**。主管在「待办」页签顶部多一个「我的 / 团队」切换，「团队」里能看到自己负责的规则下所有人的待办，以及**未分配**的待办（数据里的负责人不是系统用户），可以直接转交给合适的人。

主管每天早上另收一条「团队待办」汇总：各人待办数与超期数、超期达到规定天数的（超期升级）、未分配的；每周一还附上周各人的完成情况。

## 常见问题

**红点数字比列表里的多**：数字是未读通知和待处理待办之和，切到另一个页签看看。

**标了已处理，第二天又出现了**：数据里这张单据还没处理掉（系统每天按数据重新检查）。把单据处理掉，或者联系主管看是不是规则条件要调整。

**某条待办不该是我的**：点「转交」交给负责的同事；如果整类都分错了，请管理员检查规则里的负责人列。

**看不到某条警报**：通知只发给警报或报告里设置的推送对象（指定用户，或某个角色下的所有人）。不在推送对象里的人看不到，请联系管理员调整。
