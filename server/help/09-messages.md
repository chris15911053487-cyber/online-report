# 消息：通知与待办

「消息」集中显示系统主动发给你的内容。电脑上在左侧菜单，手机上在底部「消息」Tab；有未读时入口上显示红色数字（通知和待办的未读数加在一起）。

页面分两个页签：

- **通知**：警报、定时报告、看板每日要点等推送给你的内容，按时间倒序，一条一条留存。
- **待办**：打开时按当前数据现查的提醒（如「待我审批的单据」），处理掉了就不再显示。

## 通知

管理员配置的**警报**（如「物料低于安全库存」）和**定时报告**（如每日生产日报、看板每日要点）触发后，会同时做两件事：

1. 在系统「消息 → 通知」里给你留一条；
2. 如果你的账号绑定了钉钉，再发一条钉钉消息。

所以没绑定钉钉也不会漏看，钉钉里的消息被刷走了也能回到系统里找。

**看通知**：列表显示标题、摘要、来源（警报 / 报告）和时间，未读的标题加粗、前面有红点。点开看全文，打开即算已读。警报配置了「查看详情」按钮的，全文下方有对应按钮，可以跳到相关报表或页面。

**筛选与已读**：顶部「全部 / 未读」切换；「全部标为已读」一次清掉未读。往下翻到底点「加载更多」看更早的通知。

## 钉钉里的消息

钉钉消息的标题、正文与系统里的通知一致。消息底部的按钮：

- 警报配置了按钮（如「查看详情」）时，直接打开配置的地址；
- 其他情况显示「在系统中查看」，点开就是系统里这条通知的全文（同时标为已读）。

收不到钉钉消息时，先确认能在系统「消息 → 通知」里看到这条；看得到而钉钉没收到，一般是账号还没绑定钉钉，请联系管理员。

## 待办

待办由管理员在「管理后台 → 消息提醒」里配置，每条规则是一组按当前数据查出来的事项。点开规则看明细，逐条「标为已读」或「全部标为已读」；数据处理掉以后（查询不再返回），这条也就不再出现。

## 常见问题

**红点数字比列表里的未读多**：数字是通知和待办的未读数之和，切到另一个页签看看。

**看不到某条警报**：通知只发给警报或报告里设置的推送对象（指定用户，或某个角色下的所有人）。不在推送对象里的人看不到，请联系管理员调整。
