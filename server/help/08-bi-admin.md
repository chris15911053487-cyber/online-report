# BI 看板配置说明（管理员）

入口：**管理后台 → BI 看板管理**（仅 PC）。看板分三层维护，按顺序配置：

| 层 | 管什么 | 说明 |
|------|------|------|
| ① 查询库 | 数据与口径 | 只读 SQL、参数、输出列语义、口径、示例问法、缓存、可见角色 |
| ② 图表 | 怎么展示 | 引用一个查询 + 类型 + 列映射 + 下钻 + 默认尺寸；可被多个看板复用 |
| ③ 看板 | 组合与排版 | 全局筛选 + 选哪些图表 + 排版 |

最后到 **管理后台 → Agent 配置 → BI 看板**，把看板关联到 Agent，用户进入这个 Agent 就能看到看板。看板卡片、卡片下钻和 AI 追问都用同一份命名查询，所以看板上的数和 AI 说的数口径一致。

![BI 看板管理首页](images/bi/admin-list.png)

## 列表：查找、谁改的、什么时候改的

三个页签的列表上方有一排筛选：

- **搜索框**：按名称、标识、描述查找（图表还能搜所用查询，看板还能搜筛选名）。
- **状态**：全部 / 启用 / 已停用。
- **操作人**：只看某个人最后改过的；「未记录」是这个功能上线前保存、还没再改过的。
- **排序**：默认最近修改的在最前，也可以按标识排序。

每一行下方显示 **最后修改：日期 时间 · 操作人**（保存一次就会更新）。看板行还会列出它的筛选，如「筛选：期间、仓库」。筛选后右侧显示「显示 N / 总数」，点「清除筛选」恢复。

## 最快上手：AI 起草

「① 查询库」「② 图表」页签右上角有 **✨ AI 起草**：

1. 说一句需求，如「本月各客户销售额前 10 名」。
2. AI 读表结构写查询并试运行，SQL 报错会自己修正（最多 3 轮），再推荐 1~3 张图表。
3. 点「采用」：先在查询编辑器里核对、保存查询，再并排预览推荐的图表，勾选后一次保存。

AI 只起草，不会自动保存，一切以你确认的为准。用户 / 权限表和本系统配置表不会给 AI 看。

## ① 查询库

点「新增查询」或某条查询进入编辑，按页面上的分节填写：

1. **基本信息**：查询标识 `queryKey`（英文，创建后被图表引用，不要随意改）、名称、「回答什么问题」。
2. **SQL**：只能写单条 `SELECT` / `WITH`，参数写 `@period` 这类形式。写了 `@参数` 会自动识别到参数表。
   - SQL 下方的 **AI 修改**：一句话改口径，如「扣掉退货」「改成不含税」「加一个销售员参数」。AI 会改 SQL、同步参数和列并试运行，可撤销。
3. **参数**：类型（文本 / 数字 / 日期 / 月份 / 是/否 / 多选）、是否必填、默认值；点参数名下方的「取值」还能设可选值、选项来源和数字范围，见下一节「参数：类型、可选值与多选」。默认值可以用动态值：月份 `$thisMonth` `$lastMonth`，日期 `$today` `$yesterday` `$monthStart` `$yearStart`，年份 `$thisYear` `$lastYear`。
4. **试运行**：按参数类型生成输入框（可选值是下拉、多选是勾选框），运行后显示结果，并**自动识别输出列**。
5. **输出列**：核对每列的中文名、角色（维度 / 度量 / 时间 / 属性）、格式、单位、缩放（如 10000 = 万）。图表没写格式时就继承这里的设置，AI 也靠这些语义理解数据。
   - **AI 补全语义**：只填空着的项，已填写的不动，可撤销。
6. **示例问法**：用户可能怎么问，如「本月哪个客户买得最多」。AI 据此判断该用哪个查询。也可以在 Agent 配置里一键加为快捷提问。
7. **缓存与权限**：缓存秒数，以及可见角色（不选 = 仅管理员）。**普通用户要看到卡片，必须把他的角色加进来。**

## 参数：类型、可选值与多选

查询编辑器的「参数」表里，每个参数选一种类型，需要时再点参数名下方的 **取值** 设约束。

| 类型 | 值的样子 | SQL 里怎么用 |
|---|---|---|
| 文本 | 任意文字 | `T0.CardCode = @cardCode` |
| 数字 | 整数或小数，可设范围 | `TOP (@top)` |
| 日期 | `2026-09-01` | `T0.DocDate >= @dateFrom` |
| 月份 | `2026-09`（写成 2026-9、202609 也会自动规范） | `CONVERT(char(7), T0.DocDate, 120) = @period` |
| 是/否 | 是 / 否 | `(@openOnly = 0 OR T0.DocStatus = 'O')` |
| 多选 | 一组值，不选 = 全部 | `(@whs IS NULL OR T0.WhsCode IN (SELECT value FROM OPENJSON(@whs)))` |

**可选值**（文本、数字、多选可设）：

- **固定选项**：每行一个「值=显示名」，如 `yoy=去年同期`、`mom=上月`。传进来的值不在其中时，查询直接报错并列出可选值，不会悄悄落进 SQL 的 `ELSE` 分支算出错的数。AI 追问时也会按可选值传参。
- **来自查询**：选另一条查询，再选「取值列」和「显示列」，如客户清单查询的 `CardCode` / `CardName`。来源查询不能有必填参数；下拉里按取值列去重，最多 500 项。

**数字范围**：给数字参数设最小值、最大值，如 `top` 设 1~100，超出范围直接报错。

设好可选值后，试运行、图表固定值、看板卡片覆盖的输入框都会变成下拉；看板上建同名筛选时也会自动带出这些选项（见「③ 看板」）。

**多选的写法**：值以 JSON 数组的形式传给 SQL，用 `OPENJSON` 展开，仍然是参数绑定，不拼接字符串。`OPENJSON` 需要数据库兼容级别 130 及以上（SQL Server 2016+）；如果试运行提示 `OPENJSON` 无效，可改用 `(@whs IS NULL OR CHARINDEX('"' + T0.WhsCode + '"', @whs) > 0)`。

## ② 图表

1. 点「查询」框打开选择弹窗：左边搜索查询库（名称 / 标识 / 说明 / 列名），右边看这条查询的说明、参数、输出列和真实数据预览（可按当前图表类型或表格查看），点「使用这条查询」或双击选定。下钻每一级的查询也用同样的弹窗选。再选类型：**KPI 指标卡 / 柱状 / 折线 / 饼图 / 表格**。维度、度量会按列语义自动预选。
2. 列都从查询的输出列里下拉选择。格式、单位、缩放不填就继承列语义。
3. 个别参数可以写成固定值（如 Top N = 10）。月份等参数一般**不要写死**，留给看板的同名筛选提供。
4. **下钻**：配置下一级查询（如「客户 → 单据」），参数优先从上一级点中行的同名列取值。没配下钻时，点击只用于 AI 解读。
5. 右侧 **实时预览**：用真实数据渲染，未固定的参数会临时生成筛选条。

KPI 可以配对比列：显示增长率箭头和对比期的数值。柱状图可设横向，多个度量会画成多系列，「按系列拆分」用于长表透视。多个度量里有增长率这类百分比时，可以放到「右轴（折线）」，见下一节。

「显示数值」控制柱子、折线上是否直接标出数字：默认「自动」——只有一个度量且柱子不多（竖柱 12 根以内、横向条形 20 根以内）时标在柱顶 / 条形末端，多个度量或柱子很多时不标（以免挤在一起，可悬停或点击查看）；单条折线只标最新的那个点。个别图表可改成「显示」或「不显示」。数字按查询的缩放显示，单位写在坐标轴上。

## 同比 / 环比怎么配

要同时看今年、去年和增长率时，按「一条查询 + 一个对比方式筛选 + 三种图表」来配：

**1. 查询固定输出三列**：`Cur`（本期）、`Prev`（对比期）、`GrowthRate`（增长率），再加参数 `cmp`：`yoy` 是同比（比去年同期），`mom` 是环比（比上月）。SQL 按 `cmp` 决定对比期取哪一段，输出的列名不变，所以同一张图表在同比、环比下都能用。`cmp` 的「取值」设固定选项 `yoy=去年同期`、`mom=上月`，传错值会直接报错；期间参数 `period` 的类型选「月份」。

- 增长率写成 `(Cur - Prev) / NULLIF(ABS(Prev), 0)`：对比期为 0 时显示「—」，不会报错；用 `ABS` 是为了利润这类可能为负的数也能算出正确方向。
- 列语义里 `GrowthRate` 的格式选「百分比」；`Prev` 的中文名写 `{cmp}`，看板上会显示成筛选当前选项的文字（「去年同期」或「上月」）。
- 合计的增长率要用合计后的本期 ÷ 合计后的对比期来算，不能把各行增长率相加或平均。
- 不想手写可以用「AI 起草」，说「按月销售额同比环比」或「各客户本月销售额同比」，AI 会按这个模式写。

按月趋势（参数 `year` 数字、`cmp`），取数从上一年 1 月开始，1 月的环比也能对上去年 12 月：

```sql
WITH m AS (
  SELECT DATEFROMPARTS(YEAR(T0.DocDate), MONTH(T0.DocDate), 1) AS M, SUM(T0.DocTotal - T0.VatSum) AS Amount
  FROM OINV T0
  WHERE T0.CANCELED = 'N' AND T0.DocDate >= DATEFROMPARTS(@year - 1, 1, 1) AND T0.DocDate < DATEFROMPARTS(@year + 1, 1, 1)
  GROUP BY DATEFROMPARTS(YEAR(T0.DocDate), MONTH(T0.DocDate), 1)
)
SELECT CONVERT(char(7), c.M, 120) AS Month, c.Amount AS Cur, p.Amount AS Prev,
       (c.Amount - p.Amount) / NULLIF(ABS(p.Amount), 0) AS GrowthRate
FROM m c
LEFT JOIN m p ON p.M = CASE @cmp WHEN 'mom' THEN DATEADD(MONTH, -1, c.M) ELSE DATEADD(YEAR, -1, c.M) END
WHERE YEAR(c.M) = @year
ORDER BY c.M
```

按客户（参数 `period` 月份 `YYYY-MM`、`cmp`、`periodType`、`top`）。`periodType` 为 `month` 时只算当月，为 `ytd` 时算到当月为止的年累计（如 1~9 月累计同比）。本期、对比期用条件求和一次算出，只在其中一期有销售的客户也不会丢：

```sql
WITH r AS (
  SELECT CASE WHEN @periodType = 'ytd' THEN DATEFROMPARTS(YEAR(m), 1, 1) ELSE m END AS CurFrom,
         DATEADD(MONTH, 1, m) AS CurTo,
         CASE WHEN @cmp = 'mom' THEN m ELSE DATEADD(YEAR, -1, DATEADD(MONTH, 1, m)) END AS PrevTo
  FROM (SELECT CAST(@period + '-01' AS date) AS m) x
), r2 AS (
  SELECT CurFrom, CurTo, PrevTo,
         CASE WHEN @periodType = 'ytd' THEN DATEFROMPARTS(YEAR(DATEADD(DAY, -1, PrevTo)), 1, 1) ELSE DATEADD(MONTH, -1, PrevTo) END AS PrevFrom
  FROM r
), s AS (
  SELECT T0.CardCode, T0.CardName,
         SUM(CASE WHEN T0.DocDate >= r2.CurFrom AND T0.DocDate < r2.CurTo THEN T0.DocTotal - T0.VatSum ELSE 0 END) AS Cur,
         SUM(CASE WHEN T0.DocDate >= r2.PrevFrom AND T0.DocDate < r2.PrevTo THEN T0.DocTotal - T0.VatSum ELSE 0 END) AS Prev
  FROM OINV T0 CROSS JOIN r2
  WHERE T0.CANCELED = 'N' AND T0.DocDate >= r2.PrevFrom AND T0.DocDate < r2.CurTo
  GROUP BY T0.CardCode, T0.CardName
)
SELECT TOP (@top) CardCode, CardName, Cur, Prev, (Cur - Prev) / NULLIF(ABS(Prev), 0) AS GrowthRate
FROM s
ORDER BY Cur DESC
```

**2. 看板加筛选**：「对比方式」筛选名 `cmp`，类型选下拉，选项 `yoy` → 去年同期、`mom` → 上月（查询参数设了可选值时，点「建议建成筛选」会直接带出这些选项）。按客户的看板再加「期间口径」筛选 `periodType`（`month` → 当月、`ytd` → 年累计）。筛选名和参数同名，会自动传给所有卡片，切换一次整个看板一起变。

**3. 三种图表**：

| 看什么 | 图表 | 怎么配 |
|---|---|---|
| 总数 | KPI | 数值列 `Cur`、对比列 `Prev`；卡片显示「▲ 12.4% 较去年同期 2,918 万」 |
| 按月趋势 | 柱状 | 数值列选 `Cur`、`Prev`、`GrowthRate`，「右轴（折线）」选 `GrowthRate`：本期和对比期画成柱（左轴金额），增长率画成折线（右轴百分比）。选数值列时百分比列会自动放到右轴。左右两轴的 0 自动对齐：0% 就在柱子底边那条线上，折线在线上是增长、在线下是下降（有负增长时左轴会往下留出空间，0 以下不标金额） |
| 按客户 / 产品 | 表格 | 「涨跌着色列」选 `GrowthRate`：正数 ▲、负数 ▼ 并着色 |

「涨跌颜色」（KPI 和表格都有）：**上涨为好**（涨绿跌红，适合销售）、**上涨为坏**（涨红跌绿，适合成本、退货）；不选为中性色。

**标题和列名里的占位符**：卡片标题、副标题、列的中文名里都可以写 `{筛选名}`。下拉筛选换成选项文字，其他筛选换成筛选值，例如标题「销售额（对比{cmp}）」会显示成「销售额（对比去年同期）」。看板每日要点里的标题和列名也会这样替换。

## ③ 看板

1. **基本信息**：看板标识、名称、说明。
2. **全局筛选**：类型有月份 / 年份 / 日期 / 下拉 / 文本，默认值可用 `$thisMonth` `$thisYear` 等动态值。**筛选名和查询参数同名就会自动对上**（不区分大小写），如筛选 `period` 自动提供给所有查询的 `@period`。
   - 下拉的选项可以是 **固定选项**（每行「值=显示名」），也可以 **来自查询**（选查询和取值 / 显示列，如客户清单）。
   - 勾 **多选** 后可以一次选多个，不选 = 全部。多选筛选只能传给「多选」类型的参数，传给其它参数保存时会报错。
   - 同名查询参数设了可选值时，下拉旁会出现「带出参数的选项」，点一下即可同步。
3. **添加图表**：点画布右上角「添加图表」打开弹窗，左边搜索 / 按类型筛选图表库，右边用真实数据预览选中图表的样子（看板里已有的同名筛选默认值会带进预览），确认后点「添加到看板」（或双击列表项）。已在看板里的图表会标「已在看板」。添加时按类型自动定尺寸（KPI 1/4 宽并排在最前、折线 / 表格整行、柱状 1/2、饼图 1/3）。
4. **看板画布排版**：拖 ⠿ 换位置，拖右边缘改宽度，拖下边缘改高度。画布显示的就是真实效果。
5. 点卡片，可以在右侧改标题、查看每个参数的来源，必要时覆盖。
6. 图表需要但没有来源的参数，会提示「建议建成筛选」，可以一键生成（期间 / 月份参数 → 月份筛选、年份 → 年份筛选默认今年、日期 → 日期筛选；设了可选值的参数 → 下拉筛选并带出选项，多选参数 → 多选下拉，是/否 → 是 / 否下拉）。
7. 高级：可以切到 JSON 模式直接编辑，与表单双向切换。

**参数从哪里来**（优先级从高到低）：下钻时上一级点中的列 → 看板卡片上的覆盖 → 图表里的固定值 → 看板同名筛选 → 查询参数默认值。必填参数没有任何来源时，保存看板会报错。

## 关联到 Agent

**管理后台 → Agent 配置**，编辑 Agent，在「BI 看板」选择看板：

- 下方显示「AI 会看到的查询目录」：可以按 Agent 的每个可见角色预览，并提示哪个角色看不到哪些卡片（查询的可见角色没覆盖到）。
- 查询的示例问法可以勾选后一键加为快捷提问，保存 Agent 后生效。
- Agent 自己的可见角色决定谁能进入，每张卡片再按查询的可见角色过滤。

## 保存时的检查

- 保存查询时检查：参数的可选值、范围是否合理，默认值是否符合它们；「来自查询」的来源查询存在、没有必填参数、取值列在它的输出列里。
- 保存图表时检查：参数是否存在、用到的列是否在查询输出列里，固定值是否符合参数的类型 / 可选值 / 范围。
- 保存看板时检查：展开后每个必填参数都要有来源；多选筛选只传给多选参数。
- 改了查询 / 图表后，如果下游对不上，仍然保存成功，但会列出受影响的图表和看板卡片，请逐个检查。
- 删除限制：查询被图表用到、图表被看板用到、看板被 Agent 关联时，都不能删除。

## 对话结果收藏到看板

在 Agent 页或 AI 助手里，AI 临时用 SQL 查出的结果下方有 **📌 收藏到看板**（仅管理员可见）。点击后会在新标签页打开 BI 看板管理，点「AI 整理成查询」，AI 会把写死的月份 / 编码改成参数，补齐名称、口径和语义，并推荐图表。之后同样是先确认查询、再确认图表。

## 预警与每日要点

- **一句话设预警**：管理后台 → 预警与待办 → 一句话设预警。说一句「本月有客户销售额比上月下降超过 30%，每天 9 点提醒」，AI 从查询库选查询、写判断条件，并按当前数据试算，你补上推送对象后保存。运行时不调用 AI。触发后推送对象会在「消息 → 通知」收到一条，绑定了钉钉的同时收到钉钉消息。
- **看板每日要点**：管理后台 → 定时报告，新建任务时选「看板每日要点」并选择关联了看板的 Agent。系统按推送对象的角色读取看板数据，AI 写 3~5 条要点，附看板链接推送。表单里可以先「预览要点」。

## 常见问题

**普通用户看不到某张卡片**：检查这张卡片所用查询（以及下钻查询）的「可见角色」。Agent 配置页的查询目录预览会直接列出各角色缺哪些卡片。

**卡片没数据，但试运行有数据**：多半是参数来源不对，如年份参数被绑到了月份筛选（值是 `2026-08`）。在看板画布上点这张卡片，看右侧的参数来源。

**筛选默认值总是某个固定月份**：默认值写成了具体月份，改成 `$thisMonth`。

**卡片报「参数…的值…不在可选值中」**：传进来的值不在参数的固定选项里。检查看板同名下拉筛选的选项是否和参数的可选值一致（可点「带出参数的选项」同步），或卡片上覆盖的固定值。

**多选筛选报「不是多选参数」**：把查询里对应参数的类型改成「多选」，SQL 按「参数：类型、可选值与多选」一节的写法改成 `IN (SELECT value FROM OPENJSON(@参数))`。

**改了 SQL 后用户看到的还是旧数**：保存查询时缓存会立即失效。用户那边可以点卡片右上角 ↻ 强制刷新。
