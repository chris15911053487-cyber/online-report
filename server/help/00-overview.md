# 系统概述

version: 2026-05-16

本系统是「在线报工与生产报表」移动端应用，主要能力包括：动态报表查询、生产合并报工、批次报工、AI 报表分析、语音快捷操作。

## 界面结构

登录成功后，底部有四个主 Tab：

1. **菜单**：业务功能入口（生产报工、各类报表等，由管理员配置）
2. **AI**：智能助手，可询问系统使用方法（改密码、报工流程等）
3. **消息**：系统推送给你的警报、定时报告（通知），以及待处理事项（待办），详见「消息：通知与待办」
4. **设置**：修改密码、退出登录等

从菜单进入具体业务后，左上角「返回」可回到上一级；合并报工保存成功后会自动返回列表并保持筛选条件。

电脑上临时切到别的页面再回来，不会丢掉刚才看的内容：

- 点左侧 **「工作台」「Agent」「使用说明」**，会回到切走前打开的那张报表、那个 Agent、那篇说明书；已经在里面时再点一次，才回到对应的列表。
- **Agent** 和 **AI 助手**的对话、看板筛选都原样保留，AI 正在回答也会在后台继续；报表回来后需要重新查询。
- 点「返回」或再点一次入口，就算关掉了这个页面，下次点入口进的是列表。

## 权限说明

- **操作员**：可使用被授权的菜单、报工、报表查询；**菜单设置**仅管理员可见。
- **管理员**：额外可配置菜单、报表 SQL、AI 分析 Prompt 等。

若某菜单看不到，请联系管理员在「菜单设置」中检查是否启用及角色权限。

## 常见问题

**问：找不到某个功能？**  
答：先在底部点「菜单」，在网格中查找对应名称（如「生产报工登记」）。菜单名称因企业配置可能不同，以实际显示为准。

**问：AI 回答和界面不一致？**  
答：以本系统当前界面为准；若说明书未覆盖，请联系管理员更新配置或说明文档。
