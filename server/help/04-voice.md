# 语音控制

## 如何使用

移动端页面右侧有 **浮动语音按钮**（可拖动、贴边半隐藏）：

1. **按住** 按钮说话，松开后识别。
2. 系统将语音转为文字，匹配内置指令后 **模拟点击** 页面元素（与手动点击效果相同）。

## 在对话框里用语音提问

**AI 助手** 和 **Agent 对话**（手机「对话」页签）的输入框 **还没打字时**，右边的发送按钮会变成 **麦克风** 按钮（打了字自动变回发送）：

1. **按住** 麦克风，等提示从「准备中…」变成 **「请说话」** 再开口（太早开口第一个字可能录不到），屏幕上有音量条和计时。
2. **松开** 后识别，文字会 **填进输入框**，不会自动发送——检查一下（物料号、客户名容易听错），改好再点发送（这时按钮已变回发送）。想接着说，把输入框清空，麦克风就回来了。
3. 说错了：按住时 **手指往上滑**，提示变红「松开 取消」，松开就作废。
4. 一次最长 **60 秒**，最后 5 秒会倒计时，到时自动结束；按一下就松开（不到半秒）会提示「说话时间太短」。

用语音提问时，AI 会在回答 **第一句写明它按什么条件查的**（比如「按上个月（10 月）统计」）。听错了（比如把「上个月」听成「三个月」）一眼就能看出来，直接回一句「是上个月」即可。

说话时尽量离手机近一点、语速正常、说完再松手；车间特别吵时可以背对噪音源或走到安静处。

第一次使用浏览器会询问麦克风权限，请选「允许」；拒绝过的话要到浏览器 / 钉钉的设置里重新打开。

在这两个对话页里用右侧的 **浮动语音按钮**（或 App 自带的语音按钮）说话，文字同样填进输入框，而不是执行「打开菜单」之类的指令；离开对话页后恢复指令功能。

## 常用说法示例

- 「菜单」「返回」→ 切到底部菜单 Tab  
- 「设置」→ 打开设置（可改密码）  
- 「AI」「智能助手」→ 打开 AI Tab  
- 说出 **菜单设置里配置的菜单名称**，如「打开生产报工登记」「进入某某报表」

菜单名称以管理员在「菜单设置」中配置的 **label** 为准；可说「打开XXX」「进入XXX」。

## 限制

- 语音 **不直接调用** 报工保存等业务 API，只触发界面导航。
- 需网络及服务端百度 ASR 配置正常；识别错误时可改用触摸操作。

更详细说明见项目文档 `docs/voice-recognition-guide.md`。
